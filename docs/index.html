⚽ OpuSports

Bot de alertas de value betting para futebol — recolha de dados, modelo preditivo e notificações via Telegram.
Python 3.9+ scikit-learn python-telegram-bot API-FOOTBALL
⚠️ Projeto educativo/experimental. Não é aconselhamento financeiro e não garante lucro. Lê os riscos e limitações no README antes de usar com dinheiro real.

O que faz

📡 Recolha de dados

Jogos ao vivo, estatísticas (xG, cantos, remates, posse) e odds via API-FOOTBALL.

🤖 Modelo preditivo

RandomForest treinado para estimar probabilidades de golos e cantos, com validação cruzada.

📈 Value betting

Remove o overround das odds e calcula o Valor Esperado (EV) de cada seleção.

🔔 Alertas Telegram

Notificações formatadas com competição, estatísticas, odd e EV, mais comandos de gestão.

Início rápido

git clone https://github.com/gmagusteiro/OpuSports.git
cd OpuSports
pip install -r requirements.txt
cp .env.example .env   # preenche as tuas chaves
python db.py
python model_trainer.py
